# ⛵ 造船：硬骨帆（中式竹篾硬篷）

> **什麼時候讀**：船上有**帶水平竹篾的四邊形硬帆**（台灣帆竹筏、沙船、趕繒船、福船、鳥船這類 junk rig）才讀；步驟 7（桅與帆桁：竹篾桿）、步驟 8（帆：`battens`）、步驟 14（匯入檢查的竹篾那一行）。一般的方帆、縱帆、三角帆 ⛔ 不用讀。
> 步驟表在 `Ship_Steps`；帆、繩的一般規格在 `Ship_Rigging`、帆桁在 `Ship_Masts`。參數看 `senate cmd help sculpture`，⛔ 本檔不抄參數表。
> 範例：台灣帆竹筏 `pinnacle-tekpai-01m`（1 面帆、4 根竹篾；產生程式 `design/draft_masts.py`、`design/draft_battens.py`）。

## 1. 硬骨帆是什麼樣子（要做出來的）

- 一面四邊形帆，上緣綁**上帆桁**、下緣綁**下帆桁**，中間有 N 根水平竹篾，把帆分成 N＋1 片篷葉。
- 竹篾是**實體的桿子**，跟帆桁一樣：帆在每一根竹篾那一列整排黏在桿上、跟著帆桁一起追風轉；只有兩根桿之間的那一片布受風鼓出 ⇒ 從側面看是一片一片的肋拱，桿與布之間沒有縫。
- 收帆是**往下落篷**：上帆桁、每一根竹篾連同那一列布一起往下疊到下帆桁上（不是往上收）。

🩸 只標 `battens`、沒有竹篾桿（2026-11-18 第一版）：竹篾那一列只是比較硬的一排布 ⇒ 靜止的風看起來還好，一側風、一轉向整面往桅擠皺；從側面看，布離竹篾一大段（Tim：「目前在遊戲內效果不太理想」「中間有空隙」）。**要桿子就照第 3 節掛模型。**

## 2. 帆（步驟 8）

- 帆的 `meta` 標 `battens=<N>`（`1..16` 的整數；`kind=sail` 那一面）。⚠ 只收四邊形：三角帆設了會被擋下。
- 四個角照一般的帆綁帆桁 earing：角 0、1 綁**上帆桁**的 `earing-P`／`earing-S`、角 2、3 綁**下帆桁**的（角的順序照帆從左舷上、右舷上、右舷下、左舷下繞一圈），`bind=0,2`（上緣沿上帆桁、下緣沿下帆桁），四角 `pin`。
- 雕刻引擎與遊戲會把帆的縱向解析度對齊成 N＋1 的倍數（每片篷葉至少 4 格）⇒ 第 m 根竹篾正好落在 `v ＝ m／(N＋1)` 那一列格線上。
- 單面帆的船：`set=1`（收帆、戰鬥帆都張開；`Ship_Rigging` §9.1）。
- **幾何與角度（`roach` 與扇形斜桁；TASK-1321）**：
  - 竹篾可以統一水平（例 `pinnacle-tekpai-01m`、`meadow-tungning-trader-01m`），也可以做常見中式硬篷的**扇形漸變傾角**（下帆桁近水平、上帆桁後昂前低如 −15°~−20°，中間 N 根竹篾照 `m／(N＋1)` 線性對準該列布軸斜率、`rotate=(0, -atan2(dz, dx), 0)`）。落篷時遊戲（`battenDrop`＋`modelLocal`）會沿下帆桁列同步壓平傾角並追蹤斜桅偏移。
  - **外緣弓形弧線（可選）**：帆的 `meta` 標 `roach="<r0>,<r1>"`（兩數介於 `−0.35..0.5`：依帆角順序對 `u=0` 邊與 `u=1` 邊沿各列弦向向外拱出 `sin(π · vTop^0.85)` 倍率，兩頭上／下帆桁角仍為 `0` 不脫耳點）。每根竹篾依舊是穿過該列弧線寬度的直線剛體桿，長度要涵蓋加上 `roach` 之後的寬度且兩端伸出 ≥ 1 格。
- **貼圖**（可選）：`textures/<帆名>.png` 高度取 N＋1 的倍數（例 `battens=4` ⇒ 60 px 高，5 片篷葉各 12 px），第 m 道竹條畫在 `y ≈ m／(N＋1) × 高`（例 `y = 11..12、23..24、35..36、47..48`）⇒ 圖上的竹條跟實體桿重合。有實體桿之後圖上的竹條可以淡一點（桿本身看得到）。

## 3. 竹篾桿（步驟 7）

### 3.1 元件

- 一件竹篾子作品（例 `pinnacle-tekpai-01m-batten`：5×45×5、0.1 m、一格粗的竹、幾個竹節色），長度蓋過帆最寬那一列、兩頭各伸出帆邊 1 格以上；固定點 `pivot`（中心）、`arm-P`、`arm-S`（兩頭）。
- **N 根都引用同一件**（同一份網格）；帆是梯形、每一列寬不一樣也不用縮放 —— 布綁的是「那一列」，不是桿的端點。
- 粗細照船的大小：小船的竹篾一格（10 cm）就夠看得到；大船（福船、鳥船）可以粗一點，但**桿的中心線一定要在格心那一條**（布綁在中心線上）。

### 3.2 掛在哪、meta

- 外部模型（`work sub=model`），**掛在上下帆桁那根桅的子作品**，跟帆桁同一條桅軸、同樣的 `rotate`、同樣的 `pivot` 寫法。
- meta 照帆桁，再多兩個鍵：

  | 鍵 | 值 |
  |---|---|
  | `kind` | `yard` |
  | `yard` | `batten` |
  | `batten` | 第幾根：**從上往下數**，1 ＝ 最靠上帆桁那一根 … N ＝ 最靠下帆桁 |
  | `sail` | 帆名（一字不差） |
  | `mast` | 跟上下帆桁一樣 |
  | `pivot_anchor`、`turn_axis`、`rotate_z_deg` | 跟上下帆桁一樣 |

- ⛔ 綁哪一列**只照 `batten=`**，不照高度猜；`batten` 比 N 大的那根不綁（匯入檢查報 ⚠）。

### 3.3 擺在哪（照配方算，⛔ 不手擺）

帆角是上下帆桁的 earing ⇒ 第 m 根竹篾的轉軸：

- 高度與位置 ＝ `at_fore + (at_aft - at_fore)` 該列中心（含 `roach` 偏移後仍在同一直線上），轉軸沿該列垂直插值；若上下帆桁皆有斜度或有斜桅，每根竹篾繞自身 Y 軸旋轉 `rotate_y = -atan2(b_z - a_z, hypot(b_x - a_x, b_y - a_y))` 度（弧度在平面內沿水平垂直方向），確保滿帆、轉向與落篷同步壓平四態均為 0 縫隙；
- x、y ＝ 帆桁那條桅軸（或照斜桅在該高度的位置）；
- 那一列布的寬度 ＝ 基礎線形寬度 × `(1 + bulge(v) · (r0 + r1))`（用來確認各根竹篾長度蓋過弧線後的寬度，可分短中長幾種件或統一取最寬＋1 格以上餘裕）。

寫成一支產生程式（範例 `pinnacle-tekpai-01m/design/draft_battens.py`：不帶 `--apply` 只印每根的位置與兩頭伸出幾格；帶 `--apply` 建元件、落格、固定點、掛 N 根模型）。

## 4. 讀數（每一步都看）

- **雕刻預覽**：有桿的那一列整排釘在設計位置上 ⇒ `op=view` 從側面（順著竹篾看）每一片篷葉都是從一根桿鼓出去、到下一根桿收回來，桿與布之間沒有縫（`SCP_SculptSails` BuildParticles）。正面看：N＋2 道橫桿（上下帆桁＋N 根竹篾）、兩頭都伸出帆邊。
- **匯入**：新的竹篾模型匯入後跑 `python -I admin.py ids --id <船>`（匯入檢查「物件 id：N 件關聯／模型沒有 id」那一格）。
- **匯入檢查**（`reports/shipcheck_<船>.md` 的「竹篾」那一行）：`<帆>：竹篾 N／N 根有桿、綁住 (N × 列寬) 點、桿離那一列最遠 0.00 格`。⚠ 會報的：竹篾有幾根沒有桿、`batten` 比 N 大、桿離那一列超過 1.5 格。

## 5. 遊戲裡怎麼演（Blockside；給造船的人知道會看到什麼）

- **追風**：竹篾跟同一面帆的上下帆桁一起轉（`yard=batten` 照方帆桁轉）；綁在它上面那一列跟著轉（`29_sailrecipe.js` `rcpBattens`、`clothBindMeta`）。
- **落篷**：收帆時上帆桁、竹篾連同那一列布往下疊到下帆桁、綁在上帆桁的繩跟著往下；張帆時再升回去（`30_rig_physics.js` `battenDrop`；只是畫，航速與命中照帆的狀態立刻算）。
- **被打中**：
  - 竹篾被打斷 ⇒ 只有那一列布鬆開，帆還掛在上下帆桁上（不像一般帆桁斷了整面帆掉）。
  - 上帆桁被打飛、或桅頂那一截被打斷帶走上帆桁 ⇒ 竹篾跟著掉（竹篾自動吊在上帆桁下，**不用寫 `rests_on`**）。
  - 帆「掉了」（多半是 sheet 被打斷）⇒ 竹篾**不**跟著掉：布照樣綁在上下帆桁、竹篾上掛著。
    🩸 第一版讓竹篾跟著帆掉 ⇒ 打到甲板上 sheet 的固定處，4 根竹篾一次全沒、帆還掛著（Tim 2026-11-18「竹篾會一次全部被打掉(且命中的位置好像是船身 懷疑是打到纜索固定處?)」）。
- 沒有桿的硬骨帆（只標 `battens`）照第一版：竹篾那一列只是比較硬的布，收帆照樣往下落篷（上帆桁也往下疊）。

## 6. 換一艘硬帆船時

1. 步驟 7：上下帆桁照一般帆桁做（`yard=course` 與下面那根；⛔ 下帆桁不要標 `boom`，見 `Ship_Masts` 的 `yard` 表）＋第 3 節的竹篾桿。
2. 步驟 8：帆 `battens=<N>`、`bind=0,2`；要貼圖照第 2 節對齊。
3. 雕刻預覽從側面看一次（第 4 節）。
4. 步驟 14：匯入 ⇒ `ids` ⇒ 匯入檢查「竹篾」那一行 N／N、最遠 < 1.5 格。
5. 進遊戲轉向、收帆張帆各看一次（桿、布、上帆桁一起動）。
